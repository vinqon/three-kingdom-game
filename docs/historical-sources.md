# 三国山河 V1 历史数据与素材记录

## 1. 时间切片

本项目以公元 229 年为剧本时间。曹魏、蜀汉、孙吴的首都分别采用洛阳、成都、建业。城市归属用于构建简化策略局面，不表示当年每一个郡县边界的测绘级复原。

## 2. 地理数据方法

- 历史地名与治所研究框架参考 [China Historical GIS](https://chgis.fas.harvard.edu/pages/intro/) 和 [Harvard Center for Geographic Analysis 的 CHGIS 说明](https://gis.harvard.edu/china-historical-gis)。CHGIS 覆盖公元前 221 年至公元 1911 年的历史行政单位与聚落，可用于按时间查询历史地名。
- 城市在前端数据中保留经纬度、现代位置参照和渲染坐标。经纬度用于确定城市之间的相对方位，不直接宣称为古城遗址中心点的精确坐标。
- 黄河、长江和陆地轮廓在画布中单独绘制，主要用于帮助玩家识别中国东中部地理结构。
- 18 座城市是策略节点，不等同于 18 个完整历史行政区。相邻路线综合距离、山河通道和玩法连通性进行简化。

## 3. 可信度与游戏化调整

| 内容 | 可信度 | V1 处理 |
| --- | --- | --- |
| 洛阳、成都、建业三国都城 | A | 直接作为三方胜负目标 |
| 18 座城市的大致位置 | A/B | 以现代位置参照映射到统一经纬度画布 |
| 三国连续控制边界 | B/C | 以城市势力色晕近似表达，不绘制绝对国界线 |
| 城市间行军路线 | C | 为保证地图连通和游戏节奏进行明显简化 |
| 地形与河流 | B/C | 只影响视觉，不参与战斗计算 |

## 4. 视觉素材

- `public/assets/three-kingdoms-terrain.png` 由 OpenAI 图像生成工具为本项目生成。
- 生成目标为高视角、低多边形与手绘结合的中国山河地形，不含文字、人物、城市标记和第三方游戏素材。
- 前端使用经纬度陆地轮廓对图片进行裁切，并在画布上叠加河流、路线、汉代风格城楼和动态旗帜；原始图片不单独承担历史版图准确性。
- React 19 运行文件来自本机已安装的 Cursor 应用分发包，保留 React 的 MIT 许可要求；正式发布前应在发行包中附带相应许可证。

## 5. 商业发布前事项

V1 当前历史数据适合原型和内部测试。商业发布前应使用具有明确再发布许可的地形、水系和海岸线数据重新校准，并由历史顾问复核 229 年城市归属、古今地名对应和争议区域表述。CHGIS 可作为研究线索，但不得在未确认许可范围时直接重新分发其完整数据集。
